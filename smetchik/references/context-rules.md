# Контекст и экономная работа агента

Готовые расшифровки и результаты используй повторно; смена ИИ не разрешает новый OCR. Повторное распознавание — только по явному запросу. Выбранный ИИ не подменяй другой моделью.

Память задачи обновляй только при существенном изменении длительной задачи или передаче состояния; для короткого ответа не читай и не обновляй. Храни факты с источниками, а не хронологию. Память — указатель, не замена первоисточников; при восстановлении длительной задачи сверяй её с доступной активной веткой. Не обращайся к отменённым веткам и данным вне переданных полномочий. Режим без истории исключает чтение прежней переписки и памяти.

Права определяются текущим запуском, старые разрешения их не расширяют. Не перечитывай неизменившийся файл, если нужные данные уже есть в контексте. Если данных нет или они изменились — прочитай нужные строки/страницы. Для количества возвращай число, для поиска — нужные совпадения с контекстом, а не весь документ повторно. Не повторяй успешный вызов инструмента без новой причины.

Простой вопрос по уже полученным данным не требует MCP, повторной загрузки навыка, плана или проверки памяти. Для новой нормативной задачи применяй навык и инструменты сервера: шифры, цены и нормы не придумывай. Подключай только инструменты по текущей задаче, по необходимости расширяй набор; не считай скрытый инструмент недоступным без поиска. Ранее полученные результаты используй с учётом их даты, источника и применимости к новому вопросу.
